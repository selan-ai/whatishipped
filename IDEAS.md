# Ideas

What we would build next. None of it is promised; an issue saying which you want moves it up.

- **React Native and Flutter.** The same brandbook from a cross-platform repo, one folder per platform it ships to.
- **Drift in CI.** Run `--compare` on every merge request against the new UI test screenshots, and say which screens
  the change moved and by how much.
- **What changed between releases.** Two commits drawn side by side: the screens, states and tokens that differ.
- **Variants as states.** Light mode, large text, right-to-left and tablets, each drawn and matched like any state.
- **Accessibility from the drawing.** Contrast of every text and ground the screens actually pair, and touch targets
  under 44 points.
- **To Figma.** The drawn components and screens as frames, for teams whose design work starts there.
- **Device farms.** Screenshots captured on Firebase Test Lab or BrowserStack instead of a local simulator.
- **Web apps.** The same pages for a web front end, drawn against Playwright screenshots.
